# 多点自动点击 1.2.1

## 安装与绑定

1. 用脚本全部内容替换油猴里的旧代码并保存。若新建脚本，请关闭旧版。
2. 打开目标页面，刷新一次。
3. 点击油猴扩展，在此脚本菜单中选择“在当前页面启用点击面板（仅本地）”。页面刷新后显示面板。
4. 每个浏览器只需绑定一次；支持一个绑定页面，可重新绑定或取消绑定。

## 操作

拖准星到目标松开，或按“取点”后点击目标。每行设置点击后的等待时间，↑ 调整顺序，× 删除。

默认循环次数 0（持续循环）、循环间隔 100 ms、新增坐标等待 0 ms。升级保留已有配置。刷新后仍需手动开始；Esc 停止，Alt+S 开始/停止，切到后台自动停止。

可预览坐标、拖动标题移动面板、收起面板。支持 Pointer + Mouse、仅 Mouse、仅 Touch，建议先单轮测试。

## iframe 与限制

为支持未知域名的 iframe，元数据匹配 HTTP/HTTPS 页面。未绑定的顶层页面仅注册油猴菜单；子页面只有祖先域名匹配本地绑定站点时才注册接收器，且仅处理直接父页面传来的点击消息。

Canvas 点使用相对坐标；iframe 内的点使用外层视口坐标，改变窗口大小、缩放、滚动或游戏布局后需重新取点。iframe 未响应时，确认保存后刷新整个页面且油猴能在子页面执行。
